# 自分の思想をClaudeに教える

## 概要
自分のビジネス哲学・思考パターン・ノウハウをClaudeに蓄積させる。
これにより、Claude がより自分らしいアドバイスや提案をできるようになる。

## 課題・背景
- 毎回ゼロから文脈を説明するのは非効率
- 自分の思想が言語化されていないと、判断軸がブレやすい
- ノウハウが自分の頭にしか存在せず、失われるリスクがある

## 解決策
- `ideas/` や `knowledge/` に自分の考え方・哲学を少しずつ書き溜める
- Claude の memory 機能を活用し、自分のプロフィールに思想を追加していく
- 定期的に「振り返り」セッションを行い、気づきを言語化する
